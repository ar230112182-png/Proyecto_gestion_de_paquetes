El proyecto controla un acceso con huella digital: un sensor identifica a la persona, un 
Arduino mueve un servo y Node-RED registra el evento en MySQL. 
Cada acceso reconocido queda guardado en la base de datos 
el último acceso y los últimos 10 registros.
